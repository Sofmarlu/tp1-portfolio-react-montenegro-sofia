# TP1 - Portfolio React

## Nombre y apellido
Sofia Montenegro

## Descripción del proyecto
Portfolio personal desarrollado como Trabajo Práctico N°1 para la materia programacion 4, (UTN - Facultad Regional Tucumán). El proyecto presenta información personal, habilidades técnicas y proyectos realizados, construido con React y Vite.

## Tecnologías utilizadas
- React
- Vite
- JavaScript
- React Bootstrap
- React Icons
- CSS

## Instalación de dependencias
Clonar el repositorio y ejecutá:

npm install

## Ejecución local
Una vez instaladas las dependencias:

npm run dev


El proyecto se encuentra disponible en este link: `http://localhost:5173/` (o el puerto que indique la terminal).
